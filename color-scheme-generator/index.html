How Does it Work?

This color scheme generator specifies the midpoint value (Base) and uses a custom color function to tint (lighten) or shade (darken) the color. Simply put, it blends the specified color with white or black. The result is a much more complete suite of colors, as shown here. Furthermore, this scheme formula can also be created manually, if you wish, by following these simple steps:

  1. Open your preferred graphic software, and select a color.
  2. Put black/white on top, and gradually lower by 20% opacity.
  3. Finally, sample it with a color picker to extract the new color.
